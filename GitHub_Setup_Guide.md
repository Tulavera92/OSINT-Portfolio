# GitHub Setup Guide for OSINT Portfolio

## Step-by-step (15–20 minutes)

1. Go to [github.com](https://github.com) and sign up (or log in) with your email.
2. Click the **+** → **New repository**.
3. Repository name: `osint-portfolio` (or `tulavera-osint`).
4. Set to **Public**.
5. Check **Add a README file**.
6. Click **Create repository**.

### Upload your files
1. Download the portfolio files I prepared.
2. In your new repo, click **Add file** → **Upload files**.
3. Drag in:
   - `README.md`
   - `methodology.md`
   - `case-01-template.md`
4. Commit the changes.

### Make it look professional
- Edit the README.md directly on GitHub if needed.
- Add a short bio at the top.
- Pin the repo on your GitHub profile.

### Later steps
- Create a free Substack and mirror one finished case study.
- Add the GitHub link to your LinkedIn and future CVs.

**Tip**: Start private if you want to practice first, then switch to public once you have 1–2 solid pieces.
