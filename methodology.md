# Methodology

## Source Hierarchy
1. Primary / official documents and statements
2. Contemporaneous local media (especially Spanish-language)
3. Verified social media with context
4. Secondary analysis

## Core Tools (Free)
- Google / Yandex reverse image search
- Google Maps / Street View / Earth
- Bellingcat OpenStreetMap Search: https://osm-search.bellingcat.com/
- Bellingcat Shadow Finder
- WHOIS / DomainTools free tier
- Blockchain explorers (for financial crime)
- OSINT Framework: https://osintframework.com/

## Ethics Rules
- No doxxing of private individuals
- Focus on organizations, networks, state actors, criminal groups
- Always cite sources
- Clearly state confidence level and gaps
- Reproducible process

## Standard Output
Every public piece ends with an **Assessment** written in your own words.
